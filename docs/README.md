# Documentation index

The documentation is divided into current guides, which describe how the analyses work and how to run them, and dated records, which document decisions and results at the time they were made. Records are kept unchanged in substance because the status of each result depends on the order in which the analyses were designed and run. Records originally written in Italian are given in English translation, and each translation names the commit at which the original text is preserved.
